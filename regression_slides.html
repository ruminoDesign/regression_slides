핵심 질문

산점도에 수많은 직선을 그을 수 있다. 그 중 데이터를 가장 잘 대표하는 선은 어떻게 정의하는가?

목적함수 — SSE 최소화

SSE = Σ(yᵢ − ŷᵢ)² → min
yᵢ : 실제값  |  ŷᵢ : 예측값  |  (yᵢ − ŷᵢ) : 잔차(residual)
제곱을 취하는 이유 → 양수/음수 잔차의 상쇄 방지
  • 1각 데이터 점에서 회귀선까지의 거리 = 잔차
  • 2잔차를 제곱하여 모두 합산 → SSE
  • 3SSE가 최소가 되는 기울기(β₁)와 절편(β₀)을 수학적으로 도출
  • 4도출된 선 = 최소제곱 회귀선
VISUALIZATION — 잔차 개념도

결정계수 R²
Coefficient of Determination — 모델이 데이터 변동을 얼마나 설명하는가
기호 명칭 의미
SST 전체 제곱합 데이터 전체의 변동 크기
SSR 회귀 제곱합 모델이 설명하는 변동
SSE 잔차 제곱합 모델이 설명 못한 변동

R² 공식

R² = SSR / SST = 1 − SSE / SST
SST = SSR + SSE  |  범위: 0 ≤ R² ≤ 1
R² 해석 척도
0.0–0.3
0.3–0.5
0.5–0.7
0.7–1.0
설명력 낮음 보통 양호 높음
예시 해석
R² = 0.85 → 체중 변동의 85%를 이 모델로 설명 가능
나머지 15%는 모델에 포함되지 않은 요인들
⚠ 주의 사항 R²이 높다고 반드시 좋은 모델이 아니다.
· 변수를 무작정 추가하면 R²은 오른다 → 과적합(overfitting) 위험
· 다중회귀에서는 수정 R²(Adjusted R²)을 함께 확인
· R²만으로 인과관계를 주장할 수 없음

회귀계수의 방향과 상관관계
Regression Coefficient & Correlation — 기울기가 말해주는 것
β > 0

양의 관계

X 증가 → Y 증가
기울기가 우상향

예: 사료량 → 체중
β < 0

음의 관계

X 증가 → Y 감소
기울기가 우하향

예: 스트레스 → 산유량
β = 0

무관계

X 변화가 Y에
영향 없음

예: 귀 크기 → 체중
|β|

영향 크기

절댓값이 클수록
X의 영향이 강함

표준화 계수 비교
구분 상관계수 (r) 회귀계수 (β)
목적 두 변수의 선형 관계 강도 측정 X 1단위 변화에 따른 Y 변화량 추정
범위 −1 ≤ r ≤ 1 제한 없음 (단위에 따라 다름)
방향 부호로 관계 방향 파악 부호로 관계 방향 파악
단위 무단위 (표준화됨) Y의 단위를 가짐

다중회귀에서 계수 해석

β₁ = 3.2 (사료량, kg) 의미:
"다른 변수들이 동일할 때, 사료량이 1kg 증가하면 체중은 평균 3.2kg 증가"

→ 다중회귀에서는 다른 변수를 통제한 상태에서의 순수 효과를 나타냄
