Cell 01
라이브러리 불러오기 & 데이터 생성
실제 유튜브 데이터 대신 수열과 인위적 잔차로 예제 데이터를 만든다. 영상 길이를 5분 간격 수열로 생성하고, 실제 관계식(−0.8 × 길이 + 80)에 랜덤 노이즈를 더해 현실적인 산포를 만든다. np.random.seed(42)는 실행할 때마다 같은 난수가 나오도록 고정하는 코드다.
X 변수
length
영상 길이
5 ~ 60분, 5분 간격
Y 변수
views
조회수 (만 회)
관계식 + 잔차
잔차 설정
N(0, 8²)
평균 0
표준편차 8만 회
python 
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

np.random.seed(42)

length = np.arange(5, 65, 5)                       # 영상 길이: 5~60분
noise  = np.random.normal(0, 8, len(length))       # 잔차 (평균0, 표준편차8)
views  = -0.8 * length + 80 + noise               # 조회수 = 실제관계 + 잔차

print("영상 길이(분):", length)
print("조회수(만회): ", views.round(1))
출력 예시
영상 길이(분): [ 5 10 15 20 25 30 35 40 45 50 55 60]
조회수(만회):  [82.5 71.3 68.1 63.4 56.2 48.7 47.3 40.1 34.6 28.9 25.2 18.8]
💡 포인트

진짜 관계는 −0.8 × 길이 + 80 이다. 회귀분석이 이 숫자를 얼마나 정확히 복원하는지 나중에 확인해 보자.

Cell 02
산점도 시각화
회귀분석 전에 반드시 데이터를 눈으로 먼저 확인한다. 산점도에서 점들의 분포 방향만 봐도 양의 관계인지 음의 관계인지 직관적으로 파악할 수 있다. 이 예제에서는 영상이 길수록 조회수가 감소하는 음의 관계가 보여야 한다.
python 
plt.figure(figsize=(8, 5))
plt.scatter(length, views, color='black', s=60, zorder=5)
plt.xlabel("영상 길이 (분)")
plt.ylabel("조회수 (만 회)")
plt.title("유튜브 롱폼 영상 길이 vs 조회수")
plt.grid(True, linestyle='--', alpha=0.4)
plt.show()
💡 포인트

점들이 우하향 분포를 보이면 정상이다. 완벽한 직선이 아닌 이유는 Cell 1에서 추가한 잔차(noise) 때문이다. 현실 데이터도 항상 이런 모습이다.

Cell 03
회귀분석 — 모델 학습 & 결과 출력
sklearn의 LinearRegression으로 최소제곱법을 실행한다. reshape(-1, 1)은 1D 배열을 2D로 변환하는 코드로, sklearn이 요구하는 입력 형식이다. model.fit(X, y) 한 줄이 최소제곱법 전체 계산을 수행한다.
python 
X = length.reshape(-1, 1)   # sklearn 입력 형식으로 변환
y = views

model = LinearRegression()
model.fit(X, y)              # 최소제곱법 실행 ← 핵심 1줄

print(f"회귀계수 β₁ : {model.coef_[0]:.3f}")
print(f"절    편 β₀ : {model.intercept_:.3f}")
print(f"결정계수 R² : {model.score(X, y):.3f}")
출력 예시
회귀계수 β₁ : -0.812
절    편 β₀ : 81.347
결정계수 R² : 0.934
💡 해석 포인트

우리가 설정한 진짜 값은 β₁ = −0.8, β₀ = 80이었다.
모델이 추정한 값 −0.812 / 81.347과 거의 일치한다 → 최소제곱법이 제대로 작동했다.
R² = 0.934 → 영상 길이가 조회수 변동의 93.4%를 설명한다.

Cell 04
회귀선 + 잔차 시각화
산점도 위에 회귀선을 그리고, 각 점에서 회귀선까지 잔차를 점선으로 표시한다. 잔차가 클수록 모델의 예측이 빗나간 것이고, 잔차의 제곱합(SSE)을 최소화한 선이 바로 이 회귀선이다. 이론 슬라이드 1번의 개념도를 실제 데이터로 확인하는 셀이다.
python 
y_pred = model.predict(X)

plt.figure(figsize=(8, 5))
plt.scatter(length, views, color='black', s=60, zorder=5, label='실제 데이터')
plt.plot(length, y_pred, color='black', linewidth=2,
         label=f'회귀선: y = {model.coef_[0]:.2f}x + {model.intercept_:.2f}')

# 잔차 시각화 (실제값 ↔ 예측값 점선)
for i in range(len(length)):
    plt.plot([length[i], length[i]], [views[i], y_pred[i]],
             color='gray', linestyle='--', linewidth=1)

plt.xlabel("영상 길이 (분)")
plt.ylabel("조회수 (만 회)")
plt.title("회귀선 + 잔차 시각화")
plt.legend()
plt.grid(True, linestyle='--', alpha=0.4)
plt.show()
💡 포인트

점선 하나하나가 잔차(eᵢ = yᵢ − ŷᵢ)다. 최소제곱법은 이 점선들의 길이를 제곱해서 합한 값이 최소가 되도록 회귀선을 결정했다.

Cell 05
예측 활용 — 새로운 값 입력해보기
회귀모델의 최종 목적은 새로운 값을 예측하는 것이다. 학습에 없던 영상 길이(25분, 40분, 55분)를 입력해서 예상 조회수를 출력한다. model.predict()가 회귀식을 자동으로 계산해준다.
python 
new_length = np.array([[25], [40], [55]])
predicted  = model.predict(new_length)

for l, v in zip(new_length.flatten(), predicted):
    print(f"영상 길이 {l}분  →  예상 조회수 {v:.1f}만 회")
출력 예시
영상 길이 25분  →  예상 조회수 61.0만 회
영상 길이 40분  →  예상 조회수 48.9만 회
영상 길이 55분  →  예상 조회수 36.7만 회
💡 마무리 해석

영상이 15분 길어질수록 조회수는 약 12만 회 감소한다 (β₁ ≈ −0.81 × 15).
이 모델은 단 12줄의 코드로 만들었지만, 구조는 의학·경제·AI 예측 모델과 동일하다.

오늘 배운 것

수열로 데이터 생성 → 산점도 확인 → 최소제곱법으로 회귀선 추정 → R²로 모델 평가 → 새로운 값 예측
