Cell 01

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
import pickle

DATA_URL = 'https://raw.githubusercontent.com/ruminoDesign/regression_slides/refs/heads/main/rent_data.csv'

df = pd.read_csv(DATA_URL)
print(df.head(10))
print("---")
print(df.describe().round(1))

Cell 02
상관관계 확인
모델을 만들기 전에 각 독립변수와 월세의 관계를 시각적으로 확인한다. 상관계수 표로 수치를 보고, 산점도 3개로 방향과 강도를 눈으로 파악한다. 상관계수가 양수(+)면 함께 증가, 음수(−)면 반대 방향이다.
python 
# 상관계수 테이블
print("=== 상관계수 ===")
print(df.corr(numeric_only=True).round(2))

# 산점도 3개
fig, axes = plt.subplots(1, 3, figsize=(12, 4))
labels = ['면적 (㎡)', '역까지 거리 (m)', '층수']

for ax, col, label in zip(axes, ['area', 'dist_subway', 'floor'], labels):
    ax.scatter(df[col], df['rent'], color='black', s=40)
    ax.set_xlabel(label)
    ax.set_ylabel('월세 (만원)')
    ax.grid(True, linestyle='--', alpha=0.4)

plt.suptitle("각 변수 vs 월세", y=1.02)
plt.tight_layout()
plt.show()
출력 예시 — 상관계수

             area  dist_subway  floor  rent

💡 해석

area(면적) → rent : 0.91 — 가장 강한 양의 관계
dist_subway → rent : −0.62 — 역에서 멀수록 월세 감소
floor → rent : 0.52 — 층이 높을수록 월세 소폭 증가

Cell 03
모델 구축 & 저장
독립변수 3개로 다중회귀모델을 학습한다. model.fit(X, y) 한 줄이 최소제곱법으로 최적의 회귀계수를 계산한다. 학습된 모델은 pickle로 저장해두면, 나중에 다시 불러와서 예측에 바로 쓸 수 있다.
python 
X = df[['area', 'dist_subway', 'floor']]
y = df['rent']

model = LinearRegression()
model.fit(X, y)

# 회귀계수 출력
for name, coef in zip(X.columns, model.coef_):
    print(f"{name:15s}: {coef:.3f}")
print(f"{'절편':15s}: {model.intercept_:.3f}")
print(f"{'R²':15s}: {model.score(X, y):.3f}")

# 모델 저장
with open('rent_model.pkl', 'wb') as f:
    pickle.dump(model, f)
print("\n✅ 모델 저장 완료: rent_model.pkl")
출력 예시
area           : 1.823
dist_subway    : -0.014
floor          : 0.776
절편           : 21.304
R²             : 0.961

✅ 모델 저장 완료: rent_model.pkl
💡 해석

area 계수 1.823 → 면적 1㎡ 늘면 월세 약 1.8만원 증가
dist_subway 계수 −0.014 → 역에서 100m 멀어지면 월세 약 1.4만원 감소
R² = 0.961 → 이 3개 변수가 월세 변동의 96.1%를 설명

Cell 04
예측기 — 내 자취방 월세는?
저장된 모델을 불러와서 직접 값을 입력하면 월세를 예측해준다. 셀을 실행하면 입력창이 순서대로 나타난다. 본인이 살고 싶은 조건이나 실제 자취방 조건을 넣어보자.
python 
# 모델 불러오기
with open('rent_model.pkl', 'rb') as f:
    model = pickle.load(f)

# ✏️ 값을 직접 입력하세요
my_area        = float(input("📐 면적을 입력하세요 (㎡): "))
my_dist_subway = float(input("🚇 역까지 거리를 입력하세요 (m): "))
my_floor       = float(input("🏢 층수를 입력하세요: "))

my_input = pd.DataFrame(
    [[my_area, my_dist_subway, my_floor]],
    columns=['area', 'dist_subway', 'floor']
)

predicted_rent = model.predict(my_input)[0]

print(f"\n── 입력 조건 ──────────────────")
print(f"  면적        : {my_area:.0f} ㎡")
print(f"  역까지 거리 : {my_dist_subway:.0f} m")
print(f"  층수        : {my_floor:.0f} 층")
print(f"────────────────────────────────")
print(f"🏠 예상 월세  : {predicted_rent:.1f} 만원")
입력 예시 (33㎡ · 역 400m · 7층)
📐 면적을 입력하세요 (㎡): 33
🚇 역까지 거리를 입력하세요 (m): 400
🏢 층수를 입력하세요: 7

  면적        : 33 ㎡
  역까지 거리 : 400 m
  층수        : 7 층
────────────────────────────────

💡 실습 미션

본인이 원하는 자취방 조건을 입력해보자.
역까지 거리를 500m → 1000m로 바꾸면 월세가 얼마나 줄어드는지 확인해보자.
층수나 면적도 바꿔보며 어떤 변수의 영향이 가장 큰지 직접 느껴보자.
